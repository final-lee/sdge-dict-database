# sdge-dict-database

SDGE Dict 앱의 데이터 배포 저장소입니다. 앱은 `db-*` 릴리스의 `units.db.enc`(암호화된 데이터 스냅샷)를 받아 데이터를 갱신합니다.

데이터 출처: https://appmedia.jp/ggene_eternal/78590855
